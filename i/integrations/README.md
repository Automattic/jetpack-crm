# Integration icons

The products CRM's integrations connect to, shown with their own icons on the Core Modules and Extensions pages. `jpcrm_integration_icon_html()` prints them, and `jpcrm_premium_extension_icon()` and the `brand` key on a module say which one to use.

Each icon is the product's own, at 128px or as SVG. They are the companies' trademarks, used only to name the product an integration connects to.
